1. Geometric & Chemical Foundations of Ternary Plots

When scientists and data engineers analyze three-variable systems, standard 3D Cartesian scatter plots introduce severe perceptual liabilities: 3D perspective foreshortening warps geometric proportions, occludes background data points, and requires constant manual rotation. However, in physical chemistry, metallurgy, petrology, and machine learning, three variables frequently represent proportions of a closed whole: a + b + c = 1 (or 100%). This fundamental linear constraint reduces the system's degrees of freedom from three to two.

A ternary plot maps this 2-simplex onto an equilateral triangle. First formulated mathematically by J. Willard Gibbs in 1876, the geometry relies on Viviani's Theorem: the sum of the perpendicular distances from any interior point P to the three sides of an equilateral triangle is strictly constant and equal to the triangle's altitude H:

Viviani's Theorem Formulation
h_A + h_B + h_C = H = \frac{\sqrt{3}}{2} \times L
Where L is the side length of the equilateral triangle, and h_A, h_B, h_C represent the perpendicular distances to the edges opposing vertices A, B, and C.

Consequently, the relative altitude of any point directly quantifies its composition: a point located at perpendicular distance h_A from the base opposite vertex A possesses component proportion a = h_A / H. When a mixture contains 100% of component A, it resides exactly on vertex V_A; when a = 0%, the point lies on the base edge connecting V_B and V_C.

Critical Scientific & Engineering Domains

Ternary visualization is essential across multiple high-precision scientific disciplines:

  • Metallurgy & Phase Equilibria: Material scientists chart ternary alloy systems (such as Iron-Chromium-Nickel austenitic stainless steels or Titanium-Aluminum-Vanadium aerospace alloys) to delineate solidus/liquidus melting boundaries and phase transformations (austenite, ferrite, martensite).
  • Geotechnical Engineering & Pedology: The USDA Soil Texture Triangle classifies soil samples into clay, silt, and sand fractions, governing agricultural water retention and civil foundation bearing capacities.
  • Chemical Extraction & Liquid-Liquid Equilibria: Chemical engineers map ternary liquid systems (e.g., Water-Ethanol-Toluene) to determine binodal solubility curves, plait points, and conjugate tie-lines for liquid extraction column design.
  • Probabilistic Machine Learning & Game Theory: Data scientists visualize 3-class classification probability distributions output by Softmax layers, and evolutionary game theorists map population strategy distributions in rock-paper-scissors dynamics.

Higher-Dimensional Simplex Generalizations & The Geometry of Quaternary Tetrahedrons

The equilateral triangle is the two-dimensional member of the infinite family of regular simplices. In convex geometry, an n-simplex represents the simplest possible polytope in n dimensions: a 0-simplex is a point, a 1-simplex is a line segment, a 2-simplex is an equilateral triangle, and a 3-simplex is a regular tetrahedron. When chemical systems involve four components (such as quaternary metallurgy alloys containing Iron, Nickel, Chromium, and Molybdenum, or quaternary solvent systems in petroleum refining), the compositional state space occupies a three-dimensional tetrahedron bounded by four triangular faces.

Visualizing a 3-simplex on flat two-dimensional displays requires projecting isometric or pseudo-3D views of the tetrahedron, which introduces perspective distortion and internal visual occlusion. To maintain quantitative precision, engineers slice the quaternary tetrahedron along planar pseudobinary or pseudoternary sections—effectively fixing the concentration of the fourth component at a constant level (e.g., Mo = 5%) and rendering the remaining three degrees of freedom on a standard 2D SVG ternary plot. Understanding this dimensional reduction allows developers to build multi-tier visualization interfaces where interactive slider controls scrub through continuous planar cross-sections of higher-dimensional phase spaces.

2. Barycentric-to-Cartesian Coordinate Transformation Calculus

To render ternary data on an SVG canvas, the graphics engine must execute forward barycentric-to-Cartesian projection. Let the three vertices of an equilateral triangle in 2D SVG canvas space be defined as V_A = (x_A, y_A) (the top apex), V_B = (x_B, y_B) (the bottom-left vertex), and V_C = (x_C, y_C) (the bottom-right vertex).

Forward Barycentric Projection

Given any normalized compositional tuple (a, b, c) where a + b + c = 1 and a, b, c ≥ 0, its Cartesian SVG coordinates (x, y) represent a convex linear combination of the vertex coordinates:

Forward Barycentric Linear Combination
P(x, y) = a \cdot V_A + b \cdot V_B + c \cdot V_C
In scalar component form: x = a x_A + b x_B + c x_C   and   y = a y_A + b y_B + c y_C.

For an equilateral triangle centered within an SVG viewport of width W and height H_{view}, with side length L, the vertex coordinates are defined as:

  • x_A = c_x,   y_A = c_y - \frac{\sqrt{3}}{3} L (Top Apex)
  • x_B = c_x - \frac{L}{2},   y_B = c_y + \frac{\sqrt{3}}{6} L (Bottom-Left Apex)
  • x_C = c_x + \frac{L}{2},   y_C = c_y + \frac{\sqrt{3}}{6} L (Bottom-Right Apex)

Inverse Cartesian-to-Barycentric Inversion

When implementing interactive point picking, the engine must invert this mapping: given pointer mouse or touch coordinates (x_p, y_p), compute the corresponding compositional percentages (a, b, c). This requires solving the linear 2×2 system:

// Exact inverse Cartesian-to-barycentric projection using 2D determinants
function cartesianToBarycentric(xp, yp, vA, vB, vC) {
  const det = (vB.y - vC.y) * (vA.x - vC.x) + (vC.x - vB.x) * (vA.y - vC.y);
  if (Math.abs(det) < 1e-6) return { a: 0.333, b: 0.333, c: 0.333 };

  let a = ((vB.y - vC.y) * (xp - vC.x) + (vC.x - vB.x) * (yp - vC.y)) / det;
  let b = ((vC.y - vA.y) * (xp - vC.x) + (vA.x - vC.x) * (yp - vC.y)) / det;
  let c = 1.0 - a - b;

  // Clamping to simplex boundary [0, 1]
  a = Math.max(0, Math.min(1, a));
  b = Math.max(0, Math.min(1, b));
  c = Math.max(0, Math.min(1, c));

  // Renormalize so sum equals exactly 1.0
  const sum = a + b + c || 1;
  return { a: a / sum, b: b / sum, c: c / sum };
}

This formulation guarantees mathematical stability even when the user drags the cursor slightly outside the physical boundaries of the triangular canvas.

Vector Cross-Products & Areal Coordinates in Projective Geometry

The historical origin of barycentric coordinates traces to August Ferdinand Möbius's seminal 1827 work Der barycentrische Calcul. Möbius conceived barycentric coordinates not merely as algebraic coefficients, but as physical center-of-mass weights: if point masses of magnitudes a, b, and c are placed at the vertices V_A, V_B, and V_C of a rigid triangular plate, the entire plate balances perfectly on a pivot point located at P(a, b, c).

Geometrically, this center-of-mass balance translates into signed areal coordinates. If we connect an arbitrary interior point P to the three vertices, the line segments partition the primary triangle into three smaller sub-triangles: Δ_A = Δ(P, V_B, V_C), Δ_B = Δ(P, V_C, V_A), and Δ_C = Δ(P, V_A, V_B). The barycentric coordinate associated with vertex V_A is mathematically equivalent to the ratio of the area of sub-triangle Δ_A to the total area of the primary triangle Δ_{total}:

Areal Coordinate Formulation
a = rac{ ext{Area}(\Delta(P, V_B, V_C))}{ ext{Area}(\Delta(V_A, V_B, V_C))}, \quad b = rac{ ext{Area}(\Delta(P, V_C, V_A))}{ ext{Area}(\Delta(V_A, V_B, V_C))}, \quad c = rac{ ext{Area}(\Delta(P, V_A, V_B))}{ ext{Area}(\Delta(V_A, V_B, V_C))}
The area of each sub-triangle is evaluated via the 2D vector cross-product determinant: Area = 0.5 * |(x_1 - x_3)(y_2 - y_1) - (x_1 - x_2)(y_3 - y_1)|.

When P lies directly on vertex V_A, sub-triangle Δ_A encompasses the entire triangle while Δ_B and Δ_C collapse to zero area, yielding (1, 0, 0). Conversely, when P moves along the base edge opposing V_A, sub-triangle Δ_A has zero altitude and zero area, yielding a = 0. This areal duality provides an invaluable geometric invariant for validating client-side point picking calculations.

3. Simplex Grid Generation & Hexagonal Axis Topology

Unlike Cartesian grids composed of two orthogonal sets of parallel lines (horizontal and vertical), a ternary simplex grid comprises three distinct families of parallel isolines oriented at 60° and 120° relative to the horizontal base.

Clockwise vs. Counter-Clockwise Reading Conventions

To avoid misreading proportions, ternary diagrams adhere to strict orientation rules:

  1. Component A Isolines: Represent lines of constant a. Because vertex A sits at the top, lines of constant a are horizontal lines parallel to the base edge BC. As a decreases from 1.0 to 0.0, the isolines descend toward the base.
  2. Component B Isolines: Represent lines of constant b. These lines run parallel to the edge AC opposing vertex B, angled at 60° to the horizontal.
  3. Component C Isolines: Represent lines of constant c. These lines run parallel to the edge AB opposing vertex C, angled at 120° to the horizontal.
Component Apex Coordinate Opposing Base Edge Isoline Orientation
Component A Top Apex V_A Base Edge BC Horizontal (0°)
Component B Bottom-Left V_B Right Edge AC Slanted Upward (60°)
Component C Bottom-Right V_C Left Edge AB Slanted Downward (120°)

Procedurally generating these grid lines requires evaluating the endpoints of each line where it intersects the boundary edges of the simplex. For example, for an isoline of constant a = 0.4, the line starts at (0.4, 0.6, 0.0) along edge AB and terminates at (0.4, 0.0, 0.6) along edge AC.

Trilinear Coordinate Systems & Perpendicular Offset Equations

In classical projective geometry, mathematicians frequently distinguish between barycentric coordinates (a, b, c) and trilinear coordinates (x : y : z). While barycentric coordinates represent proportional mass fractions summing to unity, trilinear coordinates represent the raw physical perpendicular distances from point P to the three bounding line segments of the triangle.

In an equilateral triangle where all three edge lengths are identical (L_A = L_B = L_C = L), trilinear coordinates and barycentric coordinates become directly proportional: x = H * a, y = H * b, and z = H * c, where H is the triangle altitude. For general scalene or isosceles triangles, converting between trilinear and barycentric systems requires scaling by individual side lengths: a = (L_A * x) / (2 * Area). By standardizing our SVG rendering pipeline strictly on regular equilateral geometry, we guarantee that trilinear perpendicular distances scale linearly with barycentric percentages, eliminating complex trigonometric conversion overhead in high-frequency rendering loops.

5. Phase Space Boundaries, Tie-Lines & Binodal Contours

Beyond plotting discrete sample points, ternary diagrams serve as the mathematical foundation for multi-phase thermodynamic maps. In chemical and metallurgical engineering, mixtures do not always form homogeneous single-phase solutions; under specific temperature and pressure regimes, the system separates into conjugate thermodynamic phases.

Liquid-Liquid Immiscibility Envelopes (Binodal Curves)

In a ternary extraction system (e.g., Water-Ethanol-Benzene), the binodal solubility curve demarcates the boundary between a single homogeneous liquid phase and a heterogeneous two-phase immiscibility region. In SVG vector syntax, the binodal envelope is rendered as a smooth closed path using cubic Bézier splines (C commands) fitted to empirical solubility data points, shaded with translucent fills to indicate multi-phase zones.

Conjugate Tie-Lines and Lever-Rule Calculations

Within the two-phase immiscibility envelope, any overall mixture composition M spontaneously separates into two conjugate equilibrium liquid phases represented by the endpoints L_1 and L_2 of a tie-line passing through M. The relative mass fraction of each phase is governed by the classical Gibbs Lever Rule:

The Gibbs Lever Rule Formulation
\frac{\text{Mass of Phase } L_1}{\text{Mass of Phase } L_2} = \frac{\text{Distance}(M, L_2)}{\text{Distance}(M, L_1)}
The closer the overall mixture point M lies to endpoint L_1 along the SVG vector line, the greater the proportion of phase L_1 present in the physical system.

In SVG visualization engines, tie-lines are drawn as subtle dashed line segments spanning between the binodal boundaries, with intermediate tick markers indicating phase fraction ratios.

Thermodynamic Free Energy Landscapes & The Common Tangent Plane

The physical topology of phase boundaries in ternary metallurgical and chemical systems is governed by the second law of thermodynamics. At constant temperature and pressure, an equilibrium compositional state minimizes the total Gibbs free energy of mixing G_{mix}(a, b, c). When plotted over the equilateral simplex, the Gibbs energy forms a continuous three-dimensional potential surface G(a, b).

If the potential surface is strictly convex (∇^2 G > 0 everywhere), the three components are mutually soluble across all proportions, forming a homogeneous single-phase solution. However, if the energy surface exhibits a double-well concave depression, the system minimizes its free energy by separating into two conjugate phases along a common tangent plane. The locus of points where the tangent plane contacts the energy surface generates the binodal solubility curve on the 2D ternary projection, while the second derivative zero-crossings (inflection points) define the spinodal decomposition limit where spontaneous barrier-free phase separation occurs.

In our SVG vector engine, these binodal contours are rendered as smooth parametric cubic Bézier splines fitted to experimental thermodynamic databases (such as CALPHAD thermodynamic datasets), providing material scientists with visually pristine, mathematically rigorous phase maps.

Precision Coordinate Normalization & Floating-Point Epsilon Bounds

When ingesting raw experimental assay results from laboratory spectrometers or mass spectrometry instruments, raw component percentages rarely sum to exactly 100.000% due to measurement noise, trace contaminants, and instrument calibration variance (for example, reporting 49.98% A, 30.01% B, and 19.95% C, summing to 99.94%).

Attempting to map unnormalized triplets onto an equilateral simplex violates Viviani's geometric theorem: if a + b + c does not equal unity, the point cannot simultaneously satisfy all three perpendicular distance constraints, producing optical positioning errors where the point appears displaced relative to opposing grid axes. Our data ingestion pipeline applies strict closure normalization prior to rendering: each component is transformed as a_norm = a / (a + b + c), guaranteeing that the compositional triplet resides strictly within the simplex plane with zero mathematical contradiction.

6. Interactive Point Picking & Cartesian-to-Barycentric Inversion

A static ternary diagram forces users to manually squint along three angled grid axes to estimate composition percentages. A modern developer-grade SVG visualization transforms the diagram into a dynamic analytical instrument through interactive point picking.

Handling Pointer Events Across the Simplex

By attaching pointerdown, pointermove, and pointerup event listeners to the SVG canvas, users can click anywhere inside the triangle or drag an interactive cursor around the canvas. On each event, the engine captures screen coordinates, maps them through the inverse barycentric matrix, clamps the resulting tuple to [0, 1], and updates live percentage readouts in real time.

Pointer Capture & Touch-Action Compatibility

On mobile touchscreens and high-precision styluses, dragging a cursor can trigger native browser page scrolling or pinch-to-zoom gestures. To guarantee fluid interaction, the container declares CSS touch-action: none; user-select: none;, and the pointer event handler immediately calls liveSvg.setPointerCapture(e.pointerId). This ensures uninterrupted drag tracking even if the cursor temporarily drifts outside the browser viewport.

Real-Time Gesture Smoothing & Pointer Event Recovery

In high-frequency interactive canvas applications, dragging a cursor across an SVG simplex fires hundreds of pointermove events per second. If the application executes DOM mutations and re-evaluates complex layout strings synchronously within every event handler, JavaScript thread execution can lag behind the browser's display refresh cycle, inducing perceptible visual stutter and input latency.

Our ternary engine mitigates input lag by decoupling pointer event capture from DOM scene graph synchronization using a requestAnimationFrame render scheduler. When pointer events arrive, the handler simply updates volatile coordinate cache variables (lastX, lastY) without touching the DOM. The animation frame loop evaluates inverse barycentric projection and flushes DOM updates once per display refresh (typically 60Hz or 120Hz on ProMotion displays), ensuring silky-smooth point tracking with zero dropped frames.

Additionally, mobile touch interactions must handle gesture recovery gracefully. If an incoming phone notification or multi-touch palm gesture triggers a pointercancel event, our system immediately releases pointer capture via liveSvg.releasePointerCapture(e.pointerId) and smoothly snaps the active point picker to the nearest valid internal simplex position, preventing the user interface from locking into a permanent dragging state.

8. Responsive Scaling, Viewport Geometry & Crisp Rendering

Equilateral triangles demand precise aspect ratio management. In rectilinear charts, scaling horizontal and vertical axes independently merely stretches the plot without compromising quantitative meaning. In a ternary diagram, however, non-uniform scaling deforms the equilateral triangle into an arbitrary scalene triangle, warping Viviani's altitude equality and distorting angular coordinate readings.

Enforcing Strict Aspect Ratio Preservation

To preserve exact 60-degree angles across all client screens, the SVG declaration incorporates preserveAspectRatio="xMidYMid meet":

<svg viewBox="0 0 760 520" preserveAspectRatio="xMidYMid meet" class="responsive-ternary">
  <!-- Equilateral geometry preserved across all device displays -->
</svg>

This ensures that the browser's graphics rendering subsystem automatically scales the triangle uniformly, letterboxing or pillarboxing the canvas as needed without altering internal angles.

Crisp Grid Lines with shape-rendering

The dozens of angled grid lines crisscrossing the triangle can generate visual moiré patterns or blurry antialiased fringes if rasterized carelessly. Applying shape-rendering="geometricPrecision" to the 60° and 120° lines ensures that sub-pixel rasterization evaluates exact fractional geometric coverage, while the outer triangle perimeter and data markers remain sharp.

Headless Vector Asset Serialization & Publication Export

A vital architectural feature of our SVG Ternary Plot engine is standalone asset exportability. Academic researchers and patent attorneys require high-resolution vector figures capable of rendering crisply in print publications, IEEE/ACM conference proceedings, and LaTeX documents without bitmap pixelation.

When the user triggers 'Copy Standalone SVG', our export pipeline gathers the dynamic SVG tree, verifies that all presentation styling is inlined (avoiding external stylesheet dependencies), and wraps the document in compliant XML headers including the official W3C namespace xmlns="http://www.w3.org/2000/svg" and intrinsic viewBox parameters. The exported markup can be imported directly into vector editing suites like Adobe Illustrator, Inkscape, or converted cleanly to PDF/EPS via headless tools like librsvg, ensuring zero typographical or geometric degradation across digital screens and print publication workflows.

9. Inclusive Design & WCAG 2.2 AA Compliance

Complex scientific charts frequently fail accessibility audits when visual data is inaccessible to keyboard-only users or screen readers. Implementing WCAG 2.2 Level AA compliance requires providing full programmatic alternatives.

Semantic ARIA Architecture

The SVG DOM is structured with explicit ARIA roles:

  • Root Element: role="graphics-document", aria-roledescription="ternary composition diagram".
  • Interactive Cursor: role="slider", aria-label="Composition point picker", with live aria-valuenow attributes updating as the cursor moves.
  • Data Markers: role="graphics-symbol", tabindex="0", with descriptive labels: aria-label="316L Stainless Steel: 68% Fe, 18% Cr, 14% Ni".

Off-Screen Tabular Equivalent

For complete compliance, an off-screen HTML table details every sample point's exact numerical percentages, enabling screen reader users to inspect the dataset with standard table navigation commands.

Tactile Hatching & Dual-Channel Data Encoding

According to WCAG 2.2 Success Criterion 1.4.1 (Use of Color), color must never serve as the solitary visual mechanism for conveying vital quantitative information or distinguishing graphical elements. In scientific phase diagrams, coloring two immiscible phase domains in subtle pastel shades of blue and green creates severe barriers for individuals with color vision deficiencies.

To establish full dual-channel accessibility, our SVG ternary diagrams pair color with tactile SVG pattern fills. The single-phase homogeneous solution uses a clear background with high-contrast boundary strokes; the two-phase immiscibility envelope incorporates a 45-degree diagonal crosshatch pattern (<pattern id="hatch45">); and solid crystalline phases utilize stippled dot textures. Even when printed in pure black and white or viewed under extreme accessibility filters, every phase boundary remains unambiguously distinguishable to all observers.

Furthermore, each discrete sample marker features distinct geometric symbology: circles represent standard alloys, squares denote experimental batches, and triangles indicate stoichiometric benchmark controls. This multi-redundant encoding scheme ensures that researchers can interpret complex compositional topologies with complete confidence regardless of visual ability.

10. Frequently Asked Questions

What is the fundamental mathematical constraint governing a ternary plot?
A ternary plot visualizes three-component compositional systems where the variables (a, b, c) are constrained by a constant sum equation: a + b + c = 1 (or 100%). Geometrically, this constraint reduces a three-dimensional problem space into a two-dimensional planar simplex (an equilateral triangle). Any point inside the triangle represents a unique compositional mixture, where the perpendicular distance from each edge corresponds directly to the relative proportion of the opposite apex component.
How does the barycentric-to-Cartesian coordinate transformation work in SVG space?
Given three vertices V_A = (xA, yA), V_B = (xB, yB), and V_C = (xC, yC) forming an equilateral triangle in SVG space, any normalized compositional triplet (a, b, c) satisfying a + b + c = 1 maps to Cartesian coordinates via linear affine combination: P(x, y) = a * V_A + b * V_B + c * V_C. In component form, x = a*xA + b*xB + c*xC and y = a*yA + b*yB + c*yC. This guarantees that 100% of component A maps exactly onto vertex V_A, while binary mixtures along edges have zero contribution from the opposing vertex.
How do you calculate the inverse Cartesian-to-barycentric projection for interactive point picking?
When a user clicks or drags a pointer across the SVG canvas at coordinates (xp, yp), the engine must invert the transformation to recover (a, b, c). By solving the linear 2x2 system defined by triangle edge vectors, the barycentric coordinates are computed as signed triangle area ratios using determinants: a = ((yB - yC)*(xp - xC) + (xC - xB)*(yp - yC)) / det, b = ((yC - yA)*(xp - xC) + (xA - xC)*(yp - yC)) / det, where det = (yB - yC)*(xA - xC) + (xC - xB)*(yA - yC), and c = 1 - a - b. Coordinates are clamped between 0 and 1 to prevent pointer dragging outside the simplex.
How are triangular grid lines constructed across the three compositional axes?
A complete ternary grid consists of three intersecting families of parallel lines oriented at 60-degree and 120-degree angles. For component A, isolines of constant a (e.g., a = 0.2, 0.4, 0.6, 0.8) run parallel to the base edge connecting V_B and V_C. The start and end vertices of each grid line are computed by evaluating binary mixtures along the adjacent edges: one endpoint at (a, 1-a, 0) along edge AB and the other at (a, 0, 1-a) along edge AC. Repeating this procedure for components B and C forms an equilateral hexagonal coordinate grid.
What reading convention standardizes axis tick directions on ternary plots?
Ternary diagrams follow two primary reading conventions: clockwise and counter-clockwise. The international standard (utilized in metallurgy and chemical engineering) adopts the clockwise convention: to read component A, follow the grid line running from the AB edge parallel to the BC base toward the AC axis. Axis ticks are angled at 60 degrees matching the parallel isolines, and tick labels explicitly indicate increasing percentage directions to eliminate ambiguity for researchers.
How does an SVG ternary plot achieve WCAG 2.2 AA accessibility standards?
Achieving WCAG 2.2 AA requires providing non-visual and tactile access to compositional data. The root SVG container is annotated with role='graphics-document' and aria-roledescription='ternary composition diagram'. Individual data points carry role='graphics-symbol', tabindex='0' for keyboard navigation, and explicit labels (e.g., 'Alloy Sample 4: 55% Fe, 25% Ni, 20% Cr'). Furthermore, phase boundaries incorporate tactile dashed strokes and high-contrast color fills (> 3:1 against background), complemented by an off-screen accessible HTML table listing all compositional tuples.
