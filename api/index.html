IconStash API

Free, keyless, read-only access to 134,701 open-source SVG icons across 28 libraries. No signup, no API key, no rate limit.

REST-style static JSON CORS enabled No auth OpenAPI 3.1 MCP server Free forever

The API is a small set of static JSON files on the same CDN as the site. There is no application server behind it — which is why it can be free, unlimited and always available. Search runs locally in the SDK or MCP server over a compact index (~1 MB gzipped); full SVG data is fetched only for the library you pick.

Quick start

# Service metadata
curl https://iconstash.io/api/v1/manifest.json

# All 28 libraries with licences
curl https://iconstash.io/api/v1/libraries.json

# Every icon in one library (full SVG data)
curl https://iconstash.io/data/lucide.json

# Compact search index
curl https://iconstash.io/api/v1/index.json

Endpoints

EndpointReturns
/api/v1/manifest.jsonVersion, counts, licences, endpoint list, SDK/MCP pointers
/api/v1/libraries.json28 libraries: name, slug, count, licence, npm, docs URL
/api/v1/index.jsonCompact search index over all 134,701 icons (no SVG data)
/data/{slug}.jsonFull icon array for one library (existing public data file), including svgPath and viewBox
/api/v1/openapi.jsonOpenAPI 3.1 machine-readable specification
Library payloads are the site's existing public data/ files, served directly — no copy, no rewrite — so the repository stays small.

JavaScript SDK

Zero dependencies, Node 18+ and browsers

npm install @iconstash/sdk

const { createClient } = require('@iconstash/sdk');
const icons = createClient();

const hits = await icons.search('camera', { library: 'lucide', limit: 5 });
const icon = await icons.getIcon('lucide-camera');
const svg  = await icons.svg('lucide-camera', { color: '#2563eb', size: 32 });
const jsx  = await icons.snippet('lucide-camera', 'jsx');

// Unique to IconStash: one concept, all 28 libraries
const variants = await icons.compare('camera');

Available: manifest(), libraries(), library(slug), search(), getIcon(), svg(), snippet(), compare(). Point at your own copy with createClient({ base }).

MCP server for AI assistants

Let Claude, Cursor, VS Code or any MCP client search and fetch icons directly inside your editor. It runs as a local process on your machine — IconStash hosts nothing for it.

{
  "mcpServers": {
    "iconstash": {
      "command": "npx",
      "args": ["-y", "@iconstash/sdk", "iconstash-mcp"]
    }
  }
}
ToolWhat it does
search_iconsKeyword search with library / category / style filters
get_iconFull record for one icon id
get_svgSVG, JSX, CSS, HTML or data URI for one icon
compare_conceptThe same concept drawn by all 28 libraries
list_librariesAll libraries, counts and licences

Licences

Icons belong to their upstream authors. Every record carries a license and an attributionRequired flag. All sets except Solar Icons (CC BY 4.0) are MIT, Apache 2.0, ISC or CC0 and require no attribution. Check the terms and each library's own licence before commercial use.

Terms of use

No authentication, no rate limit and no cost. Responses carry Access-Control-Allow-Origin: * so they work from browsers and build tools. Please cache responses and avoid re-downloading the full index on every request — it is versioned and CDN-cached.
